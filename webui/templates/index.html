How the checks work

The model never states a number. It picks the eight CVSS metrics; the score is computed in code. A model never asked for a number cannot invent one.

Two sources of truth. Every claim must trace to the scanner output or a local CWE catalogue — CVEs, CWEs, URLs, scores and impact language are each checked against them.

Verified in code, not by the model. The process that invented a CVE will happily confirm it is real, so verification runs against data the model cannot influence.

Redacted, never silently dropped. An ungrounded claim is replaced with a visible marker and a reason. A defence whose failure mode is invisible is worse than none.

The simulated model is a deterministic stand-in that fabricates on a fixed subset, so the checks have something to catch with no key. It is not evidence about how any real model behaves.
